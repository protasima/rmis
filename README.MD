# Моделирование динамики состояний системы при хакерской атаке

Учебный проект по дисциплине **«Риск-модели ИБ»**.  
Программа визуализирует риски и устойчивость информационной системы, моделируя процессы переходов между состояниями безопасности с помощью **систем дифференциальных уравнений Колмогорова** для марковских процессов.

## 📌 Описание логики работы
1. **Нормальный режим (t < $t^*$):** Система функционирует в штатном режиме. Графики вероятностей состояний $p_i$(t) рассчитываются путем численного решения системы уравнений Колмогорова (метод Radau) на основе исходных параметров ИБ.
2. **Момент атаки ($t = t^*$):** В случайный целочисленный момент времени $(t^*)$ происходит хакерская атака. Графики фиксируют мгновенный математический скачок (разрыв непрерывности): вероятности компрометации пересчитываются под новые начальные условия. На оси времени графически выводится красная метка $(t^*)$.
3. **Стабилизация и адаптация $(t > t^*)$:** Система переходит на новые уравнения динамики рисков и стремится к предельным вероятностям. Программа автоматически фиксирует момент выхода в эпсилон-окрестность установившегося режима $(t^')$, подсвечивает область адаптации и рассчитывает метрику времени восстановления $(\Deltat= t^' - t^*)$.

## 🚀 Ключевые особенности реализации
* **Динамический рендеринг:** Использование `matplotlib.animation.FuncAnimation` для плавной отрисовки в реальном времени.
* **Математическая точность разрывов:** Реализация чистых скачков на графиках (примечание - считаем, что переход системы из отказа 
к нормальному функционированию происходит мгновенно)
* **Адаптивная ось времени:** Автоматическое внедрение и цветовое кодирование критических точек $(t^*)$ и $(t^')$ на оси координат при любом выбранном шаге сетки.
* **Дополнительная информация:** В консоли выводятся значения вероятностей в момент времени $(t = t^*)$, а момент повторного выхода системы на предельные вероятности
рассчитывается путем сравнения численных значений решений СДУ и аналитических предельных вероятностей (решение СЛАУ, полученной из системы Колмогорова путем подстановки нормирующего уравнения) с точностью &epsilon = 0.0001.

## 🛠 Зависимости и запуск

Для работы проекта необходим Python 3.10+, все зависимости в файле requirements.txt:
```bash
pip install -r requirements.txt
```

Необходимо настроить файл **solve_nmdq.py** (вставить свою СДУ) **main.py** (параметры симуляции, начальные условия, точность совпадения вероятностей и т.д.)

**Запуск симуляции:**
```bash
python main.py
```

## 📂 Структура проекта
* `main.py` — основной скрипт: генерация сценария атаки, консольный вывод таблиц сравнения вероятностей и запуск интерактивной анимации (`matplotlib.pyplot`).
* `solve_nmdq.py` — получение численного решения: в файле определяется СДУ и методом `solve_ivp` из библиотеки `scipy` находится численное решение СДУ.
* `visualize.py` - построение графика вероятностей без моделирования атаки;
* `solve_amdq.py` - получение аналитического решения СДУ (силами `sympy`).
